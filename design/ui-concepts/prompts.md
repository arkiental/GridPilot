Generated with the built-in image-generation tool. The attached application screenshot informed the functional brief; it was not edited. The desktop thumbnails in these mockups are illustrative.

## 01 — Focus

Use case: ui-mockup.
Create a polished high-fidelity Windows 11 desktop window-management utility concept for GridPilot. A straight-on, pixel-sharp 2D application UI design, not a marketing website, not a perspective device mockup. Show one complete compact floating utility panel with comfortable padding on a quiet desktop backdrop. The current product screenshot is a functional reference only, not a design to reproduce.
Non-negotiable main interaction: a precise SIX-COLUMN BY SIX-ROW grid of thin continuous lines must be OVERLAID DIRECTLY ON A LOW-RESOLUTION SCREENSHOT THUMBNAIL OF A WHOLE DISPLAY showing several overlapping application windows and its taskbar. The thumbnail must retain a natural 16:9 display aspect ratio. Use an illustrative desktop with a 3D texturing app showing a gray hard-surface model, a small file-browser window, and a code editor/browser behind it. Those underlying windows must remain visible through the grid. Grid lines should be visible but quiet. Select the LEFT THREE COLUMNS across ALL SIX ROWS using one transparent colored rectangle with a crisp outline; desktop content must still show through that selected region. The screenshot is slightly low-resolution, the interface chrome and text are sharp.
Keep window title and display selector concise. No giant app title, tagline, redundant 'ARRANGE WINDOW' heading, resolution/DPI dump, scrollbars, overwhelming preset button wall, gradients, neon bloom, or decorative cards. Main title is 'Substance 3D Painter'. Include a small 'GridPilot' identifier, 'Main display', '6 × 6', a compact group of placement controls, undo/settings/close icons, and a discreet footer 'Release to place · Esc to cancel'. Clear hierarchy and strong contrast. This is a real usable compact tool, not a dashboard. Do not invent stats, charts, notifications, or task lists. Use deliberate geometry and crisp modern typography.

CONCEPT 01 — FOCUS. Best balanced redesign: a compact charcoal panel around 520 logical pixels wide, softly rounded 12px corners and a restrained warm-gray border.

Move normal application windows by holding modifiers and dragging anywhere inside them.

- Enable **Settings > General > Move windows by dragging anywhere**. It is off by default, including for existing settings. **Ctrl + Alt + left-drag** is the default; the modifier combination is configurable.
- Release the mouse while holding the modifiers to keep the move. **Escape** or releasing a required modifier restores the original frame. **Undo last placement** restores a completed move.
- Ordinary input passes through when disabled, paused, using a different modifier combination or targeting an excluded window. The gesture pauses while GridPilot placement/settings panels are open.
- Maximized, fixed-size, borderless/fullscreen, owned dialog, tool, desktop/taskbar, hidden/minimized, unresponsive, protected and administrator windows are excluded. GridPilot does not request elevation or change privileges.
- Physical pointer coordinates, relative grab-point preservation across DPI resizing, title-bar reachability and verified recovery are retained.

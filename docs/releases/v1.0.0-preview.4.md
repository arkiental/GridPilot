Recursive grid now previews placement over your visible desktop and supports multi-cell selection.

- Thin grid lines and a restrained orange highlight show live proposed bounds while your desktop and windows remain visible.
- Click places one cell. Hold left-click and drag in either direction to select current leaves, including unequal nested cells; release places their axis-aligned bounding box. Escape cancels before commit.
- **A** divides every eligible leaf one level. Configure or clear this picker-only shortcut under Settings > General. Middle-click undoes a bulk division as one step. Depth and window minimum limits still apply.
- Fixed false minimum blocking caused by treating current/restored size as a minimum after a failed query, clamping app overrides to larger system defaults, and retaining invisible borders in standard maximized-window minimums. Unknown/default limits are labeled estimates. App refusals retain exact placement verification and recovery.
- Original HWND/process capture, physical work-area/DPI geometry, right-click subdivision and placement Undo remain intact.

Local validation: Release build with warnings as errors, portable packaging, independent source review and real desktop UI screenshots. **Local test suites and native automated assertion harnesses were skipped at the owner's explicit request.** Prior assertion totals do not validate this release. Existing GitHub build/core-check and release workflows remain unchanged and their results are recorded independently. Mixed-DPI/multi-monitor, custom chrome, protected/elevated/RDP apps and application-specific minimum behavior remain manual limits.

Recursive grid placement adds a 2×2 picker for the active desktop window.

- Right-click divides only that leaf; middle-click undoes the last successful division globally; left-click places; Escape cancels.
- Configure Recursive grid and maximum depth in Settings → General. New installations use Ctrl+Alt+G. Existing settings leave the new shortcut empty to preserve your bindings. Default depth is 4 (initial grid depth 1; range 1–8).
- Cells and divisions respect measured native minimum sizes. A bounded 250 ms query uses a conservative current/restored-size fallback when limits are unavailable. Exact placement refusal triggers verified recovery; app-specific rules can still prevent placement.
- Work-area cells use physical pixels, exclude the taskbar, and preserve odd edges. Focus and Draw placement remain available.

Download **GridPilot-win-x64.zip**, extract the entire folder, and run GridPilot.exe. The portable package includes the existing optional Install.ps1/Uninstall.ps1 scripts and documentation. Verify the ZIP with **SHA256SUMS.txt**. This is an unsigned Windows x64 preview.

Validation and remaining hardware/application limits are in docs/VALIDATION.md and docs/RECURSIVE_GRID.md. Hosted CI verifies compilation/core checks and builds the portable package; interactive Windows checks use disposable owned fixtures.

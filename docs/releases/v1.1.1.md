# GridPilot 1.1.1

## Fixed

- Drawing a selection in the preview now applies when you release outside the grid. The destination clamps to the nearest grid edge, including fast drags and Ctrl-drags.
- Ctrl-click picking, Alt-swap cancellation, Escape/capture-loss cancellation, and preset editing retain their existing behavior.

## Downloads

Use the Setup.exe installer to upgrade, or extract the portable ZIP. Existing settings are preserved. SHA256SUMS.txt contains checksums for both downloads.

## Validation

Release build, core tests, focused selection-release regression tests, and native grid-placement tests passed. Independent source review found no concrete defects. Actual hardware outside-release routing and mixed-monitor dragging remain manual checks. The broader native suite has a recursive-grid timeout assertion failure also reproduced on unchanged 1.1.0.

# GridPilot 1.1.0

Download **GridPilot-1.1.0-Setup.exe** for Windows 11 x64. It includes the .NET runtime.

## Install or update

Quit GridPilot from its tray menu, then run the installer. The same installer handles new installations, upgrades and same-version repair. It recognizes earlier GridPilot setup installations and reuses the installation folder and selected shortcut options. It refuses to replace a newer executable. No uninstall is needed before updating.

Updates are manual: download and run the newer installer from GitHub Releases. This release does not add a background updater.

## Your settings

All saved shortcuts, grids, placements, scenes, arrangement preferences and appearance settings live in **Documents\GridPilot\settings.json**, outside the program installation folder. Windows' actual Documents location is used, including redirected/OneDrive Documents. The normal `.bak` recovery file lives beside it.

On first launch, existing settings from `%LOCALAPPDATA%\GridPilot` are copied into Documents if no Documents settings exist. The original files are kept; migration also keeps copies in `Documents\GridPilot\migration-backup`. A corrupt primary can migrate from a valid backup. If migration fails, GridPilot stops with a message instead of overwriting the old settings. Updates and uninstall leave these settings alone.

## Features

- Configurable width and height shortcuts followed by a cell count, plus movement snapped to the selected grid.
- Main grid opens with the cursor at the preview center and stays within monitor work-area edges.
- Main grid closes after placement unless **Keep open** beside **Auto arrange** is enabled for that session.
- Saved overlap reflow preference, disabled by default.
- New-install activation shortcut: **Alt+Shift+Space**. Existing shortcuts are preserved; configure new span shortcuts in Settings > General.
